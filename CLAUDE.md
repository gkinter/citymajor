# CityMajor

AI-generated city building game.

## Stack

Next.js 16 + React 19 + TypeScript (App Router) | Tailwind + shadcn/ui | AI SDK v6

## Key Directories

```
app/              → Pages and routes
components/       → React components
lib/              → Utilities and shared logic
.claude/          → Claude Code configuration (kit-managed)
```
