# GLTF Assets Directory

This directory contains the 3D meshes generated by the Meshy.ai pipeline for the CityMajor web client (R3F).

## Folder Structure

Assets are organized by **Era** to facilitate lazy-loading and chunking as the city progresses through time in the simulation.

```
web/public/assets/gltf/
├── frontier/
│   ├── res_low_frontier_00.glb
│   ├── com_frontier_00.glb
│   └── ...
├── industrial/
│   ├── res_high_industrial_00.glb
│   ├── ind_industrial_00.glb
│   └── ...
├── postwar/
│   └── ...
├── modern/
│   ├── svc_modern_00.glb  # Service buildings default to modern
│   └── ...
└── future/
    └── ...
```

## Loading Strategy

- The R3F client utilizes `@react-three/drei`'s `useGLTF` hook to load these assets.
- Ensure that instances of the same archetype use `InstancedMesh` to keep draw calls to a minimum.
- Building State (e.g., abandoned, constructing) and material variation hints (defined in `BUILDING_ARCHETYPE_3D.md`) are applied procedurally at runtime via shader materials, NOT by swapping meshes.

## Post-Processing

All `.glb` files in these directories MUST:
1. Have their pivot point positioned at the bottom-center (0, 0, 0 ground plane).
2. Be scaled to represent exactly 1 simulation story in height (unit scale).
3. Be optimized (textures compressed, unnecessary nodes flattened).
